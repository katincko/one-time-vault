One-time vault

A one-time link the server cannot read.

Your browser encrypts the secret before it leaves. The server keeps only encrypted data, and deletes it on the first read.

This holds as long as your browser runs this site's own code. The README explains the limits.

  1. 1
    Your browser encryptsAES-GCM with a new 256-bit key. The server gets the encrypted data and the settings you chose.
  2. 2
    The key stays in the linkIt goes after the #, which browsers never send to a server.
  3. 3
    One read, then goneReading and deleting are one step on the server. A second read looks like a link that never existed.
